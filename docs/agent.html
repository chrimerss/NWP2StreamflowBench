Ungauged-basin agent

A Claude-backed hydrologic-modelling agent calibrates the dCREST model on the training gauges of a split and predicts daily discharge in held-out, anonymised basins it never saw. Google's Harness² refines the agent's own harness (prompts, skills, scripts) between attempts. The baseline is dCREST's own differentiable optimizer: a parameter-learning network trained by gradient descent through the model on the same training gauges. Everything is scored on the 1989–1999 benchmark test period with USGS observations neither side sees.

Protocol

  • Data. CAMELS-US v1.2 Daymet basin-mean forcing and USGS discharge (Newman et al. 2015; Addor et al. 2017), Oudin PET. The rebuilt record reproduces the released dCREST-CAMELS test NSE (median 0.662) exactly.
  • Folds. 665 basins in 5 region-stratified random folds; each fold is held out once as ungauged and the other 532 basins are donors. The pilot uses 30 region-stratified targets of fold 1.
  • What the agent sees. Donor forcing for 1980–2014, donor discharge only for 1999-10 to 2008-09, released donor parameters, static attributes with anonymous IDs and coordinates rounded to 0.1°. Targets: forcing and attributes only. Web tools are disabled and every rollout is audited for data downloads.
  • Scoring. Daily NSE and KGE per target over 1989-10-01 to 1999-09-30, after the 3-year spin-up the released parameters were calibrated with.
  • Agent. OpenCode executor and Harness² improver, both on Claude through a direct Anthropic API key (Harness² patched to keep the key; it otherwise routes Claude through Vertex AI).
