NWP2StreamflowBench

Error propagation from NWP precipitation to streamflow. Daily basin-mean precipitation from each forecast model drives the calibrated dCREST model (dCREST-CAMELS v1.0 parameters) on CAMELS-US catchments from a common analysis-forced state; simulated discharge is scored against USGS daily observations with the Nash–Sutcliffe efficiency (NSE), per lead day and per NOAA climate region.

Method

  • Hydrologic model. dCREST (differentiable CREST, lumped, daily) with the released dCREST-CAMELS v1.0 parameter set (665 catchments, calibrated on Daymet). Parameters are used as published; nothing is recalibrated.
  • Analysis forcing. gridMET (4 km) precipitation, Tmin/Tmax and Oudin PET, area-weighted over GAGES-II basin polygons, from 2023-01-01. The analysis-forced run supplies the model state at every initialisation and the reference ceiling.
  • Forecast experiment. For each 00 UTC initialisation, precipitation on lead days 1…14 is replaced by the model's basin-mean forecast (06–06 UTC accumulation windows, matching the gridMET day); temperature and PET stay at analysis values, so differences isolate precipitation error. Forcing enters the model with a one-day lag to reproduce the Daymet observer-day convention the parameters were calibrated under.
  • Scoring. For each lead, the forecast discharge valid on each day is collected across initialisations into one time series per basin and scored against USGS daily mean discharge (converted to mm/day over the CAMELS area) with NSE and KGE over a window common to all leads. Basins need at least 60 valid days. Summaries are medians (and quartiles) across basins; regions follow NOAA/NCEI climate regions by gauge state.
