# Vendored copy of dCREST

`dcrest` 1.0.0, vendored from https://github.com/Skyan1002/dCREST at commit
`8350b3e942bd4e14444d141ed47d81d1b876687c` (MIT licence, see `LICENSE` in this
folder; copyright HyDROS Lab, University of Oklahoma).

The upstream repository stopped resolving in October 2026, which broke
`pip install` of this project. The package source is unchanged; only this note
and the licence file were added. The released dCREST-CAMELS v1.0 parameter set
used by the benchmark lives in `data/params/`.
